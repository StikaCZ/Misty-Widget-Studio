# System / Pulse – auto hardware artwork (v4.6.9)

The Normal style reads CPU model/vendor/cores/threads from `/proc/cpuinfo`, NVIDIA name/metrics from `nvidia-smi` when available, and other GPU vendor/model from `/sys/class/drm` (optionally `lspci`). No hardware model is hardcoded in widget settings; no external network or API is used.

- **AMD Ryzen 7 5700X** → keeps the original CPU illustration unchanged.
- **Other AMD, Intel, and generic CPUs** → neutral chip illustration with automatically populated CPU family/model and vendor, plus accurate core/thread counts.
- **NVIDIA GeForce RTX** → keeps original RTX graphics card/fans; detected model (e.g. RTX 5060) is shown in the card header.
- **AMD Radeon / Intel Arc / NVIDIA non-RTX / unknown GPU** → neutral dual-fan hardware artwork with detected vendor badge, model in the header. If a kernel/driver does not provide GPU metrics, unknown fields display `--` instead of an invented number.
- Supported NVIDIA metrics are unchanged; basic AMD/Intel sysfs usage/temp/VRAM are displayed where the kernel exposes them.
- The other 16 widgets, including original plant, brightness, weather and pets, have not been modified.

Display requires the **Normal** style. This is a static analysis/isolation-tested beta: real KDE rendering on your desktop has not been tested. Run `python3 ~/.local/share/plasma/plasmoids/local.samuel.systempulse/contents/scripts/metrics.py` for detection diagnostics.
