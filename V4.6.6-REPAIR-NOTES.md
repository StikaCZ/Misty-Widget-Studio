# Misty v4.6.6: Original Plant / Updates / Brightness repairs

- **Plant:** original green leafy foliage and original pot unchanged from v4.6.5.
  - Main QML uses the bundled script path rather than a hard-coded home directory.
  - Robust JSON update-check helper: fresh `checkupdates` (pacman-contrib) and cached `pacman -Qu` fallback, with a clear CACHED or STALE label; never silently claims a fresh update count when only cached data is available.
  - Clicking the plant or middle-clicking manually refreshes; checks every 30 minutes; watchdog protects against forever-checking state.
- **Display / Light:** uses KDE PowerDevil's per-display D-Bus service first, including supported external monitors, then uses Linux sysfs for internal backlights.
  - Actual available display names and levels are queried from the service; one hardware operation only when the slider is released.
  - Clearly explains unavailable monitors instead of displaying a permanently blank slider.
  - Uses no sudo, no network, no direct DDC/CI writes. PowerDevil determines what the hardware supports.
- **Remaining widgets:** same source as v4.6.5, including Weather / Planet.
- **Pets:** Eyeball/Eye of Cthulhu remains removed; Penguin, Gecko and Slime kept.
- **Testing:** static checks and isolated script tests; visual runtime checks on user's PC still required.

## Troubleshooting on your PC

If Plant shows CACHED, install `pacman-contrib` and check network connectivity, then click plant.
If Brightness / Light says no displays, open the built-in KDE **Brightness & Colour** widget and verify monitor DDC/CI support (or whether software brightness is exposed by PowerDevil). Check that your monitor's OSD has DDC/CI enabled. You cannot control every external monitor if KDE cannot see it.

Tests from Konsole:

```bash
python3 ~/.local/share/plasma/plasmoids/local.samuel.updateplant/contents/scripts/check-updates.py
python3 ~/.local/share/plasma/plasmoids/local.samuel.brightnessslate/contents/scripts/brightness.py list
```
