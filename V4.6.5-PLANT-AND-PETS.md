# Misty v4.6.5 — original plant and pets only

- **Original plant:** 7 original green leafy foliage SVGs plus 7 corresponding original pot SVGs are bundled under `widgets/local.samuel.updateplant/contents/images/` from the previously produced `update-plant-easy-resize.zip`. The main Update Plant QML was **not modified**. Existing settings remain in place.
- **Removed pet:** the Eye of Cthulhu/eyeball is not an option in the pet selector, is not selectable in the runtime, and is not in the sprites or the Terminal art. Old saved `eyeball` values display the penguin until another pet is selected.
- **Old promotional image:** `Terminal-Pet-Preview.png` was removed because it still showed the deleted pet.
- **No other runtime changes:** other QML, configuration, helper scripts, weather and colour styling are byte-for-byte identical to v4.6.4. This is a narrowly scoped update, not a new attempt at changing the colour implementation.

## Installation

Extract this ZIP; inside its single top folder run `bash install.sh` as your normal KDE desktop user (never sudo). Then `systemctl --user restart plasma-plasmashell.service`. The installer creates a dated backup. To revert this installation, run `bash restore.sh` from this folder and restart Plasma again.

## Limitations

Automated checks verify files and an isolated installer run; this version has not been rendered on your actual KDE Plasma desktop.
