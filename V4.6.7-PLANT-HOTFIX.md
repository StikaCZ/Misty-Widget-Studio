# Misty Widget Studio v4.6.7 — Plant loading hotfix

This is a minimal update built from the full v4.6.6 collection.

- Fix `widgets/local.samuel.updateplant/contents/ui/main.qml` by removing the second declaration of `readonly property string details`. Earlier release duplicated this property at lines 158 and 173, preventing KDE Plasma from loading the widget.
- Preserve the first, more informative tooltip and original green leafy plant SVG files.
- Preserve the Weather / Planet, brightness, and other 16 widgets byte-for-byte.
- Existing Plasma widget settings are preserved by the installer.

## Install

Extract the ZIP, open a terminal inside the extracted folder, then run:

```bash
bash install.sh
systemctl --user restart plasma-plasmashell.service
```

## Testing

Static checks verify the duplicate is gone, all widget metadata is present, and Python/Bash scripts have valid syntax. Actual Plasma GUI rendering wasn't tested here. If you already ran the one-command fix, reinstalling this package is optional.
